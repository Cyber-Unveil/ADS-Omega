# ADS-Ω™ Governance --- Public Summary

**Source:** ADS-Ω-CONST-003\
**Publication class:** PUBLIC-SUMMARY\
**Authority:** Public derivative only.

## Governance model

**Cyber Unveil International, LLC** is the ADS-Ω™ Approval Authority and
intellectual-property owner.

The **ADS Framework Office** is the permanent framework steward
responsible for architectural integrity, single-source-of-truth
discipline, artifact engineering, traceability, and formal framework
dispositions.

An **Independent Technical Authority (ITA)** may perform skeptical
technical review and issue findings. The ITA does not own ADS-Ω™
definitions or silently rewrite controlling artifacts.

## Governance sequence

**Framework Office → Artifact → ITA Review → Framework Office
Disposition → Repository Update → Cyber Unveil Approval**

## Single-source-of-truth rule

Every ADS-Ω™ concept has one authoritative owner and one authoritative
definition.

## Frozen architecture

Structural changes to the frozen Enterprise Architecture require
governed review and an Architecture Decision Record where warranted.

## Publication authority

Repository presence does not itself authorize publication. Public
release is separately controlled by Cyber Unveil International, LLC.
